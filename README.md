# Friction

Friction helps you use your Android phone more intentionally. Choose which apps you can use freely, which should interrupt you with a pause, and which to block while you're focusing.

Everything stays on your device. No account, internet connection, analytics, or cloud sync is needed.

## Install

You'll need a phone running **Android 13 or later** and a Friction APK (the Android installation file).

1. Transfer the APK to your phone if it isn't already there.
2. Open it and follow Android's installation prompts. If prompted, allow the app opening the file to install apps from this source.
3. Open **Friction**.

## Set up Friction

1. In Friction, tap **Accessibility settings** and enable the Friction accessibility service. This lets Friction identify the app you're using and display pauses or blocking screens. It does not read screen text.
2. Return to Friction and check that it shows **Accessibility service connected**.
3. While Friction is **OFF**, use **Find an app** to choose an app and set its policy:

   | Policy | What it does |
   | --- | --- |
   | **Allowed** | Lets you use the app freely. |
   | **Interrupted** | Pauses you after a set amount of use, with an optional daily limit. |
   | **Blocked** | Blocks access while Friction is on. |

4. Optionally, tap **Choose / replace photos** to add images that remind you why you want to focus.
5. Tap **Turn on Friction**.

Home, calling, and Android Settings remain accessible.

## Customize your pauses

For an **Interrupted** app, you can set:

- **Initial use:** how long you can use the app before the first pause. The default is 10 minutes.
- **Repeat use:** how much more use is allowed between later pauses. The default is 5 minutes.
- **Daily cap:** an optional total daily allowance. Leave it blank for no daily limit.

Short visits add up, so closing and reopening an app doesn't restart its allowance.

Under **Edit timing**, you can change how long a pause lasts and how long you need to stay away from an app before its session resets. The defaults are a **30-second pause** and **25 minutes away**. A session reset does not clear the daily total.

Timing fields use seconds: for example, enter `600` for 10 minutes or `1500` for 25 minutes.

## Turn off Friction or change settings

Tap **Turn off Friction…**, keep the confirmation screen visible for 30 seconds, then confirm. Tap **Keep focusing** to cancel.

Once Friction is off, you can edit app policies, timing, and photos. Turning it off resets app sessions but preserves daily usage totals.

From a blocking screen, **Exit** takes you to your home screen. **Turn off Friction** opens the same confirmation flow.

## Troubleshooting

- **Friction says the accessibility service is disconnected:** open **Accessibility settings**, enable Friction, then return to the app and check its connection status.
- **You can't edit settings:** turn Friction off using the confirmation flow first.
- **A motivation photo is missing:** use **Choose / replace photos** to select it again. Pauses still work with text when a photo is unavailable.
